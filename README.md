# Odin Recipes

A simple recipe website created as part of The Odin Project curriculum. This project demonstrates basic HTML skills and website structure.

## Description

This is a collection of recipe pages that showcases different dishes including:
- Lasagna
- Pancakes
- Fries

Each recipe page contains detailed instructions and ingredients needed to prepare the dish.

## Project Structure

```
odin-recipes/
├── index.html          # Main page with recipe links
├── recipes/           # Directory containing recipe pages
│   ├── lasagna.html
│   ├── pancake.html
│   └── fries.html
└── README.md          # This file
```

## How to Use

1. Clone this repository to your local machine
2. Open `index.html` in your web browser
3. Click on any recipe link to view the detailed recipe

## Technologies Used

- HTML5

## Purpose

This project was created as part of The Odin Project's curriculum to practice and demonstrate:
- Basic HTML structure
- Creating and linking multiple HTML pages
- Working with lists and links
- Organizing files and directories
